# Lua Mac

مدير macOS تجريبي يركّز على Steam الخاص بـWindows وألعاب Steam الفردية التي تعمل دون اتصال ولا تستخدم Anti-Cheat. يستهدف بناء Apple Silicon على macOS 26.

## المتطلبات

- Mac بمعالج Apple Silicon.
- macOS 26 للاختبار المستهدف؛ الحد الأدنى المحدد حاليًا في الحزمة هو macOS 13.
- Xcode يتضمن Swift 6 أو أحدث.
- محرك Wine مجاني ومتوافق مع Apple Silicon مثبت بشكل منفصل.

## التشغيل أثناء التطوير

من Terminal على Mac:

```sh
swift run
```

## الحصول على نسخة DMG

كل push إلى `main` يشغّل GitHub Actions على runner فعلي بمعمارية Apple Silicon وmacOS 26. بعد نجاح البناء، نزّل ملف `Lua-Mac-macos26-arm64.dmg` من قسم **Artifacts** في صفحة التشغيل. ملف الـDMG موقّع محليًا بتوقيع ad hoc فقط، وليس موثقًا من Apple؛ قد تحتاج إلى الضغط على التطبيق بزر Control واختيار **Open** عند أول تشغيل. لا يحتاج البناء إلى جهاز macOS محلي، لكن اختبار الألعاب يحتاج Mac فعليًا.

## إعداد Steam

اختر من التطبيق الملف التنفيذي `wine` الذي وفره محرك مجاني ومتوافق مع Apple Silicon، ثم نزّل `SteamSetup.exe` من Valve وشغّله عبر زر التثبيت. يحفظ المدير Steam في Wine Prefix مستقل ويسجل الإخراج تحت:

```text
~/Library/Application Support/MacWineManager/
```

## حدود النموذج الأولي

- لا يضمّن محرك Wine أو Steam أو يثبتهما تلقائيًا؛ اختيار المحرك وتنزيل Steam يدوي.
- يطلق Steam عبر Wine فقط؛ لا يتضمن بعد مدير مكتبة ألعاب أو إعدادات DirectX/Metal أو مثبت محرك.
- المجانية شرط تصميم: لا يعتمد النموذج على CrossOver أو D3DMetal المملوكين. يلزم اختيار مكونات مجانية متوافقة والتحقق من تراخيص توزيعها قبل تضمينها.
- النطاق الأولي ألعاب أوفلاين لا تستخدم Anti-Cheat؛ لا توجد محاولة لتعطيل أو تجاوز أنظمة الحماية.
- يلزم الإنترنت لتسجيل الدخول وتنزيل الألعاب، وقد يتطلب Steam تسجيل الدخول مرة أخرى أو تفعيل Offline Mode. دعم اللعب دون اتصال يختلف حسب اللعبة.
- لا يضمن تشغيل جميع ألعاب Steam؛ يلزم اختبار كل لعبة على محرك الرسوميات وإصدار Wine المستهدف.
- GitHub Actions يبني حزمة `.app` و`.dmg` على macOS 26 Apple Silicon، لكنه لا يحاكي تشغيل Wine أو Steam أو الألعاب.
- البناء غير موثق من Apple، لذا سيعرض macOS تحذيرًا عند أول تشغيل. التوزيع العام الموثق يحتاج حساب Apple Developer وشهادة Developer ID وإعداد notarization.
